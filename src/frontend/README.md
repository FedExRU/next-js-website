# Frontend APP Layer

The frontend layer is responsible for the application's visual interface and user interaction. Abstracting away from the backend's implementation details, it receives data and sends requests exclusively through the BFF layer, using Next.js API routes.

The frontend layer is built using React and Next.js, and it uses the Material UI library for styling and components.

The frontend layer is built using Feature-Sliced Design (FSD).
